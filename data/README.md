# Local Data Notes

The raw HBSC files are not tracked in Git.

Expected local layout:

- `data/raw/`: raw wave `.dta` files from HBSC Belgium Flemish
- `data/interim/`: cleaned wave-specific datasets generated by `01_data_build.do`
- `data/final/`: pooled analysis dataset generated by the pipeline

The main final output is:

- `data/final/hbsc_pooled_BEFL_final.dta`

If you move the repo, no code edits should be needed as long as you run Stata from the repository root and call `do code/master.do`.
