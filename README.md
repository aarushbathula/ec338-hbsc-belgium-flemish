# EC338 HBSC Belgium Flemish

This repository is a small replication package for an economics project on sibling gender composition and academic achievement among adolescents in Flanders, Belgium, using HBSC repeated cross-section data.

## What The Project Does

- Builds a harmonised pooled dataset from the raw HBSC waves
- Constructs sibling composition indicators and analysis samples
- Estimates ordered probit and OLS specifications for the main results
- Exports publication tables and the final write-up assets

## Repository Layout

- `code/`: Stata do-files for data build, analysis, and table/figure export
- `data/raw/`: local-only raw HBSC inputs
- `data/interim/`: intermediate cleaned wave files
- `data/final/`: final pooled analysis dataset
- `output/tables/`: LaTeX tables generated by the pipeline
- `output/figures/`: any figures created by the pipeline
- `output/logs/`: Stata logs
- `paper/`: manuscript source

## How To Run

Run the full project from the repository root in Stata:

```stata
do code/master.do
```

That pipeline will:

1. Build wave-specific cleaned files
2. Append and harmonise the pooled dataset
3. Estimate the main models and robustness checks
4. Write LaTeX tables and logs into `output/`

## Data Conventions

This repo intentionally does not track the raw HBSC `.dta` files.

- Put the wave files in `data/raw/`
- Leave `data/interim/` and `data/final/` for generated files
- Keep any generated tables in `output/tables/` and logs in `output/logs/`

See [data/README.md](data/README.md) and [output/README.md](output/README.md) for the local file conventions.

## Software

- Stata 18 recommended
- `estout` package for table export

The scripts are now written to use the project root rather than a machine-specific absolute path.

## Notes

- Raw HBSC data remain local-only and are excluded from Git
- Archived do-files are preserved for provenance, but the active pipeline is `code/master.do`
- If you add new outputs, place them under `output/` so the ignore rules keep the repository clean
