1. Overview

This repository contains a fully reproducible empirical project analysing how sibling gender composition affects perceived academic achievement among adolescents in Flanders (Belgium), using the HBSC 2006–2014 repeated cross-section dataset.

The project replicates and extends the classical empirical strategy in the siblings-as-natural-experiments literature. Our primary contribution is a harmonised three-wave Belgian dataset and a clean causal identification design focused on the single-sibling subsample.

This repository follows a three-file do-file architecture, enabling full reproducibility:
	1.	01_data_build.do
	•	Builds all cleaned wave-specific files
	•	Harmonises variable names
	•	Pools waves and constructs final analysis dataset
	2.	02_analysis.do
	•	Runs all econometric models
	•	Produces stored estimation sets for export
	3.	03_tables_figs.do
	•	Converts estimation results into LaTeX tables
	•	Generates all figures (if any)
	4.	master.do
	•	Runs the entire pipeline end-to-end

All raw data is excluded from the repository for confidentiality.

3. Replication Instructions

Prerequisites
	•	Stata 17 or 18
	•	estout package installed 

Step 1 — Add raw data

Place HBSC Belgum-Flemish .dta files in:

```data/raw/```

Step 2 — Run full project

From the repository root:

```stata -b do code/master.do```

This will:
	1.	Build wave-specific cleaned files
	2.	Produce final pooled dataset
	3.	Estimate all models (Tables 3–9)
	4.	Generate all LaTeX tables into output/tables/

Expected outputs

After running master.do, you should see:
	•	data/final/hbsc_pooled_BEFL_final.dta
	•	output/tables/table1_grouped.tex
	•	output/tables/table2_balance.tex
	•	output/tables/table3_main_results.tex
	•	…
	•	output/logs/master.log
